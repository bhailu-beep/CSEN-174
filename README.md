# Project Name
CompleteC: An interactive online coding platform for learning and practicing C++.

## Description
Many undergraduate students studying Computer Science and Engineering at Santa Clara University may have prior experience in Python and Java, but not in C/C++. This makes it harder for them to keep up in lower-division courses, many of which are taught in C/C++. We created CompleteC so these students can benefit from additional practice that aligns directly with their courses and receive feedback instantaneously to support their learning.

This project was built during September - December 2026 in CSEN 174: Software Engineering.
